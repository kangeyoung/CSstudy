1. 웹
웹은 브라우저로 서비스를 요청하고 처리해주는 과정이다.
클라이언트는 http 프로토콜에 따라 request하고 웹 서버는 처리해 response한다.
http 프로토콜의 특징으로는 서버가 response 후 연결을 끊는 비연결성(Connectionless)과 연결을 끊은 뒤 클라이언트의 상태를 저장하지 않는 무상태성(Stateless)이 있다.

2. 쿠키와 세션
http 프로토콜에 따라 서버는 연결했던 클라이언트의 상태를 기억하지 않는다.
클라이언트는 http 프로토콜에 따라 request하고 웹 서버는 처리해 response한다.
쿠키는 탈취당할 위험이 있기 때문에 비중요정보(ip주소, 브라우저 등)을 담고 세션에 중요 정보(id, 개인정보)를 담는다.

  • 캐시
    • 캐시 데이터를 response할 때 서버가 주고 그 데이터를 로컬은 캐시 파일로 변환해 사용한다.
    캐시유효기간은 기본 24시간(인메모리 캐시)이고 이 기간 동안은 캐시 파일이 필요하면 인메모리 캐시나 하드디스크(로컬에 저장)에서 꺼내 사용할 수 있다.
    서버에 요청하지 않아도 되므로 서버가 종료되더라도 불러올 수 있고, 불러오는 속도도 빠르다.

3. Html 문서 정의
서버의 response에는 상태코드와 헤더, 본문으로 구성되는데 본문에 요청한 데이터가 들어간다.
서버가 html 문서를 가지고 있고 클라이언트의 request에 따라 서버가 html문서를 response한다.
클라이언트의 request에 따라 서버가 response할 때 주는 웹페이지를 구성하는 코드문서이다.
클라이언트는 Html 문서를 랜더링해 웹페이지를 로드한다.

4. 정적문서/동적문서
Html은 기본적으로 화면이 바뀌지 않는 정적문서이다.
클라이언트의 request를 받아 내용이 바뀌면 화면 전체를 새로 랜더링한다.
동적문서는 클라이언트의 request를 받아 내용이 바뀌면 바뀐 부분만 새로 랜더링한다.
동적문서를 만들기 위해서 Javascript(로컬)+Ajax(서버 응답)을 사용한다.
